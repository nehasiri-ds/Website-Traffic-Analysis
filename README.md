# 📊 Website Traffic Analysis

## 🔍 Overview
This project analyzes website traffic data to understand user behavior, engagement, and conversion trends.

## 🛠 Tools Used
- Python (Pandas, Matplotlib)
- Jupyter Notebook

## 📈 Key Insights
- Organic traffic contributes the highest sessions.
- Product and Pricing pages generate the most conversions.
- Blog page has higher bounce rate.
- Contact page shows high engagement.
- Paid traffic needs optimization.

## 📊 Visualizations
- Traffic Source Analysis
- Page Conversion Analysis
- Daily Traffic Trend

## 📁 Files
- Dataset: website_traffic.csv
- Notebook: website_traffic_analysis.ipynb
- Graphs: PNG files

## 🚀 Outcome
This project helps businesses improve website performance and conversion strategy.
